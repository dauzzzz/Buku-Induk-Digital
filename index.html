Panduan Input Nilai dari Hasil Print Out (Kertas Fisik)

Apakah bisa tanpa mengetik ulang nilainya?

Ya! Anda dapat menggunakan bantuan foto/scan dokumen atau teknik salin-tempel (copy-paste) kilat ke template Excel aplikasi.

1

Foto / Scan Lembar Print Out

Ambil foto lembar cetak rapor menggunakan kamera HP dengan pencahayaan terang agar angka nilai dan NISN terbaca jelas.

2

Gunakan Template Cepat Aplikasi

Unduh tombol Template Nilai (.xlsx) di bawah, lalu cukup salin baris nilai dari lembar print out ke file Excel tersebut (atau gunakan fitur Google Lens/OCR foto untuk menyalin teks tabel ke Excel secara otomatis).

3

Impor ke Buku Induk

Unggah file Excel yang sudah terisi melalui tombol Pilih File Nilai. Nilai akan otomatis masuk dan terhitung pada Menu Pratinjau Dokumen!
